A fast drop-in for makefun-site 1.0.0 that builds the same static sites, byte for byte, in about a third of the CPU time.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `MAKEFUN_INPUT_DIR`), answers each one with `run` from `solve.js`, and writes `/output/answers.json` (or `MAKEFUN_OUTPUT_DIR`). `solve.js` is a dependency-free ES module: `run(input)` returns the output tree that makefun-site 1.0.0's build returns for the case's site.
